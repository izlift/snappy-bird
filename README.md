# Snappy Bird

A small Flappy Bird-style game built with Python and Pygame.

## How to run

1. Install Python and Pygame.
2. Open a terminal in this folder.
3. Run:

```bash
python snap.py
```

## Controls

- Press Space, Up Arrow, or X to flap
- Avoid the pipes and keep the bird in the air

## Goal

Score points by passing through gaps in the pipes without crashing.
